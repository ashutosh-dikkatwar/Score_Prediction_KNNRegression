# 🎓 Student Exam Score Prediction using KNN Regression

A machine learning project that predicts student exam scores based on personal details, study habits, attendance, sleep patterns, and other learning-related factors.

The application is built using **Python** and **Streamlit**, with a trained **K-Nearest Neighbors (KNN) Regression** model to generate predictions through an interactive web interface.

## 🚀 Project Overview

The goal of this project is to demonstrate how a trained machine learning model can be used in a simple web application.

Users can enter student details, select different options from dropdown menus, and view the predicted result generated by the model.

## ✨ Features

- Interactive and user-friendly Streamlit dashboard
- Student information input form
- Dropdown menus for categorical features
- Numeric inputs and attendance slider
- Prediction using a saved KNN Regression model
- Display of the predicted result
- Summary of the entered student details
- Error handling for prediction issues

## 🛠️ Technologies Used

- **Python** — Main programming language
- **Pandas** — Preparing input data for prediction
- **Scikit-learn** — Machine learning model
- **Streamlit** — Web application interface
- **Pickle** — Loading the saved model

## 📊 Input Features

The application currently uses 11 input features:

| Feature | Description |
|---|---|
| Age | Student's age |
| Gender | Student's gender |
| Course | Student's course category |
| Study Hours | Hours spent studying per day |
| Class Attendance | Attendance percentage |
| Internet Access | Availability of internet access |
| Sleep Hours | Hours of sleep per day |
| Sleep Quality | Reported sleep quality |
| Study Method | Preferred study method |
| Facility Rating | Rating of available facilities |
| Exam Difficulty | Difficulty level of the exam |

**Prediction target:** Exam score.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/ashutosh-dikkatwar/Score_Prediction_KNNRegression.git
```

### 2. Open the project folder

```bash
cd Score_Prediction_KNNRegression
```

### 3. Create a virtual environment (recommended)

For Windows:

```powershell
python -m venv venv
```

Activate it in PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install the required libraries

```bash
pip install -r requirements.txt
```

### 5. Run the application

```bash
streamlit run app.py
```

Once the application starts, open the local URL displayed in your terminal. Streamlit commonly uses:

```text
http://localhost:8501
```

## 🧠 How It Works

1. The user enters student details and study-related information.
2. The application converts categorical selections into numeric values.
3. The input data is arranged in a Pandas DataFrame.
4. The saved KNN Regression model generates a prediction.
5. The predicted value is displayed on the Streamlit dashboard.

## 📈 Machine Learning Model

This project uses **K-Nearest Neighbors Regression**.

KNN Regression estimates a numerical value by using nearby examples from the training data. The result depends on the training data, feature values, distance calculation, and model configuration.

The model is loaded from `KNN_regression.pkl`.

**Important:** The categorical mappings and input features must match the original model training process. If preprocessing or feature scaling was used during training, the same transformations must also be applied during prediction.
